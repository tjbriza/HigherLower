# Visual Pattern Evidence

## Core visual language

The target design repeatedly uses:

- Dark navy surfaces
- White outlines
- Offset colored backing/shadow layers
- Space Mono typography
- Fine grid background
- Circular/radio-style selection indicators
- Strong mode-accent color variants

## Hero

- Main outlined wordmark
- Per-word offset accent layers:
  - Higher: magenta
  - Or: cyan
  - Lower: purple/periwinkle
- Screenshot evidence should override conflicting Figma layer names.

## Domain selection

Selected state:
- filled magenta center indicator
- offset magenta text treatment

Unselected state:
- empty circular indicator
- outlined text without visible offset layer

The four domain states are variants of one selector system, not four separate screens.

## Gameplay mode accents

- Classic: purple
- Time Attack: magenta
- Co-op: yellow

Mode accent is applied to shared structural primitives including:
- back control offset
- comparison-card offset
- OR badge offset

## Gameplay action family

Higher:
- cyan fill
- upward arrow
- white offset layer

Lower:
- downward arrow
- white offset layer
- magenta in Classic and Time Attack
- yellow in Co-op

## Player identity

Observed player colors:
- Player 1: cyan
- Player 2: magenta
- Player 3: yellow
- Player 4: green

Co-op supplied gameplay directly confirms Player 1 and Player 2 usage.
